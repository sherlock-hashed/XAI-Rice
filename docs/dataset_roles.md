## 1. Executive Summary & Separation Invariants

In accordance with strict IEEE publication and scientific integrity guidelines, all datasets incorporated in the **XAI-RiceGuard** project are allocated immutable roles. Cross-contamination between training data and external test data is strictly prohibited.

```

+------------------------------------+-----------------------------------------------+
| Dataset                            | Role & Permitted Lifecycle Scope              |
+------------------------------------+-----------------------------------------------+

+------------------------------------+-----------------------------------------------+
```

## 2. Detailed Dataset Role Definitions

### 2.1 RiceLeafDiseaseBD (Primary Development Dataset)
- **Source:** Mendeley Data (`10.17632/86s4jzj2m4.2`)
- **Role:** Primary Training, Validation, and Internal Testing.
- **Classes:** Healthy, Blast, Brown spot, Leaf smut, Rice Tungro, Sheath blight.
- **Lesion Annotations:** Contains YOLO bounding box text files in `Annotated images ( visual with labels)/<class>/labels/` along with visual overlays.
- **Usage Restrictions:** All primary model training, architecture selection, loss function experiments, and internal validation must occur exclusively on splits derived from this dataset.

### 2.2 Sethy et al. Rice Leaf Disease Image Samples (External Test Dataset)
- **Source:** Mendeley Data (`10.17632/fwcj7stb8r.2`)
- **Role:** External Independent Benchmark / Cross-Dataset Generalization.
- **Expected Size:** 5,932 images across 4 classes (Bacterialblight, Blast, Brownspot, Tungro).
- **Usage Invariants:**
  - **NEVER** include Sethy images in training sets.
  - **NEVER** use Sethy images for hyperparameter tuning or early stopping.
  - **NEVER** use Sethy images for model selection.
  - Exclusively evaluated post-hoc as a held-out external benchmark.

### 2.3 RiceLeafDisease-BD5 (External Field Domain Dataset)
- **Source:** Mendeley Data (`10.17632/sjkptpgv79.2`)
- **Role:** Out-of-Distribution (OOD) and In-the-Wild Field Robustness Evaluation.
- **Classes:** Blast, Narrow_Brown_Spot, Normal_Leaf, Sheath_Blight, Tungro.
- **Semantic Rule:** `Narrow_Brown_Spot` is biologically and visually distinct and **MUST NOT** be automatically merged into `Brown Spot`.
- **Usage Invariants:** External evaluation only; strictly isolated from training/validation loops.

### 2.4 RiceSeg-5932 (XAI Ground Truth Segmentation Masks)
- **Source:** Mendeley Data (`10.17632/92jc6w6mcy.1`)
- **Role:** Ground Truth Lesion Masks for Quantitative XAI Faithfulness & Localization.
- **Expected Size:** 5,932 pixel-level binary masks matching the Sethy image collection.
- **Usage Invariants:**
  - **NOT** an image training dataset.
  - Used solely as ground-truth spatial masks to evaluate attribution map overlap (IoU, Dice, Pointing Game, Energy inside lesion) generated by XAI algorithms (Grad-CAM, Integrated Gradients, SHAP).
